# Design Engineer Portfolio

A premium, high-performance UI/UX portfolio built with Next.js, Tailwind CSS, and Framer Motion. This project showcases a dual expertise in design and frontend engineering, featuring interactive case studies, smooth animations, and a focus on accessibility.

## 🚀 Tech Stack

- **Framework:** [Next.js 15 (App Router)](https://nextjs.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Deployment:** [Vercel](https://vercel.com/)

## ✨ Features

- **Dynamic Case Studies:** Project details are driven by a centralized data configuration, allowing for easy updates and additions.
- **Visual Highlights:** Each project supports multiple high-quality screenshots and deep-dives into technical implementation.
- **Modern UI/UX:** Features glassmorphism, fluid transitions, and a responsive design optimized for all devices.
- **Performance Optimized:** Leverages React Server Components and optimized image handling for lightning-fast load times.
- **Direct Contact:** Integrated WhatsApp and Email contact options.

## 📁 Project Structure

- `/app`: Next.js App Router pages and layouts.
- `/components`: Reusable UI components and section layouts.
- `/lib`: Data configurations and utility functions.
- `/public`: Assets, screenshots, and visual highlights.

## 🛠️ Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/MMfrontend-developer/Muhyideen_Muhammad.git
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
